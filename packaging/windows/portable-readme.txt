DevCentr — portable Windows x64

This zip is the portable build (no installer). Unzip and run DevCentr.exe.
Keep libfreetype-6.dll beside the executable.

For Start Menu, uninstall, and a setup wizard, download
DevCentr-windows-x64-setup.exe from the same GitHub release instead.

Docs: https://docs.devcentr.org
