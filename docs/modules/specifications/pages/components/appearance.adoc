= Appearance (code font)
:navtitle: Appearance
:description: DevCentr code/terminal font preference — Cascadia Mono default, JetBrains Mono optional.

DevCentr uses a dedicated **monospace** face for the integrated terminal and other code panels. UI chrome stays on the normal UI font.

== Choices

[cols="1,2", options="header"]
|===
| Face | Role

| link:https://github.com/microsoft/cascadia-code[**Cascadia Mono**]
| **Default.** No ligatures — better for tables, grids, and judging column alignment (Nu `table` output, logs, diffs).

| link:https://www.jetbrains.com/lp/mono/[**JetBrains Mono**]
| Supported alternate. Good coding face; ligatures optional at the OS/editor level, but DevCentr asks for the Mono family name as installed.
|===

Do **not** default to Cascadia *Code* (ligatures) for DevCentr terminals. Mono is the recommendation.

== In the app

. Open **Appearance** in the top bar.
. Pick Cascadia Mono or JetBrains Mono.
. Optionally set **repository terminal** shell preference (`auto` prefers Nushell when `nu` is on `PATH`) and **Env refresh: inject and run**.
. Save. Stored in `~/.dev-center/ui-settings.json` as `codeFontFace`, `terminalShell`, and `envRefreshAutoRun`.

New terminal command blocks pick up the face immediately. Reopen panels that were already open if they still show the old face. The Auto-run checkbox on the terminal env chrome also persists `envRefreshAutoRun`.

Fallbacks if the chosen face is missing: the other recommended mono, then Consolas, then Courier New.

== Install (Scriptbook)

Do not paste a host-specific `winget` line into this spec. PlayTime binds `cli.install` from `equivalence-rules-cli`.

[cols="1,2",options="header"]
|===
| Face | Playbook in `dev-centr/scriptbook`

| Cascadia Mono
| `examples/fonts/install-cascadia-mono.cmk` (tool id `cascadia-mono`)

| JetBrains Mono
| `examples/fonts/install-jetbrains-mono.cmk` (tool id `jetbrains-mono`)
|===

Further first-class monos (Fira Code, Iosevka, Monaspace, JetBrains Mono Nerd Font) have playbooks in the same folder. They are **not** Appearance radios yet.

*Today:* the human runs `scriptbook run … --catalog …/equivalence-rules-cli/catalog/tools.sdl`.
*Next:* Appearance **Install** when `scriptbook` is on PATH (same "binary on PATH" pattern as UniConfig). Do not reimplement exec in the dialog.

Member wiring and **preview spec** (editable code sample, not a pangram bitmap): team-docs `how-to/font-lock.adoc` on team.docs.devcentr.org.

== Preview (spec, not shipped)

The Appearance dialog does not yet preview the face.

When it does:

* The preview is an **editable** monospace field wearing the selected face (pangram + a short D sample). Typing updates immediately.
* Cascadia Mono preview forces ligatures off.
* If the face is missing, say so and point at the Scriptbook playbook. Do not render Consolas and label it JetBrains Mono.

A full font-manager module (project Fontsource lock, OFL in-tree, web-use cards) is later. DevCentr is the first client of that library -- not a Suitcase clone.

== Outside DevCentr

Strong recommendation for editors and terminal hosts used with Dev-Centr workflows:

* Prefer **Cascadia Mono** (or JetBrains Mono) in Windows Terminal / Cursor / VS Code for terminal and editor monospace.
* See xref:general-knowledge:reference/recommended-tools.adoc[Recommended Tools].
