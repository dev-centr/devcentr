== Context7 submit reference and architecture

The specifications module now has two pages for the same package.

* xref:specifications:components/context7-submit.adoc[Context7 documentation submit] is the desktop contract: the overview button, the dialog fields, and what the window does not do.
* xref:specifications:reference/context7-submit.adoc[context7-submit] is the lookup page: program flags, URL classification, exit codes, environment variables, and `submitSource`.
