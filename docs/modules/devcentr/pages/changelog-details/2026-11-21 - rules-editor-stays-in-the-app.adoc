== Rules editor stays in the app

The Rules page is the product rules editor. The sidebar entry, the home button Open the rules editor, and the right-hand list Templates on this computer all open that page. Install more templates opens the extensions store at https://devcentr.org/extensions?type=rules-template . Install writes a pointer into `%USERPROFILE%\.dev-center\extensions\catalog.json`. The template body stays in its repository.

The organization site keeps that store and the rules-template filter. It does not host a second editor. Spec: xref:specifications:extensions-catalog.adoc[Extensions catalog].
