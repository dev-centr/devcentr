= Project recognizer (relocated)

Stack and role recognition now lives in the OpenShellOrg **project-map** library, consumed as the DUB registry package `project-map` (`~>0.1.3` from https://code.dlang.org/packages/project-map).

* Stacks: `profiles/stacks/` (inside the DUB-fetched package or, as a developer fallback, the hive clone)
* Roles: `profiles/roles/`
* D API: Dub package `project-map`

This directory keeps a thin compatibility shim (`recognizer.d`) so DevCentr imports stay stable.
Local `*.sdl` copies here are legacy; prefer the project-map corpus.
